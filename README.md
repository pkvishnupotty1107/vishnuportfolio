# Vishnu Potty P K — Angular Portfolio

A responsive, single-page portfolio built with Angular standalone components and plain CSS.

## Requirements
- Node.js 20.19+ (or a compatible Node.js version supported by Angular 20)
- npm

## Run locally
```bash
npm install
npm start
```
Open `http://localhost:4200`.

## Production build
```bash
npm run build
```
The production output is generated under `dist/vishnu-portfolio/browser`.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `src/app/app.component.html` with your preferred email.
2. Verify role dates, project descriptions, technology versions and experience figures.
3. Add a PDF resume to `src/assets/` and add a download link if desired.
4. Publish the generated `dist/vishnu-portfolio/browser` folder to Azure Static Web Apps, Firebase Hosting, Netlify, Vercel or GitHub Pages.

## Portfolio content
The content is based on details shared in the conversation and the LinkedIn URL supplied by the user. The LinkedIn page itself has not been independently verified. Please review all claims before publishing.
